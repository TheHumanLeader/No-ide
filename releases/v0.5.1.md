**构建反馈不再只藏在日志里。** 点击“应用改动”后，实例下会持续显示本次更新任务、后端实际阶段和耗时；结束后保留结果，不是一闪而过的提示。

- 真实阶段：等待资源 → 检查改动 / Maven 模型 → 构建与复核 → 应用或启动 → 结果；不伪造百分比。
- Maven 构建显示本次重编与复用模块，可以展开范围和原因。
- 明确区分“已是最新”“已原地热替换”“新进程启动 / 端口就绪”“构建完成但需重启”“失败”“取消”。端口响应不等于业务健康检查。
- “取消本次构建”只取消当前配置的共享构建，不停止原有实例；取消请求绑定任务编号，旧请求不能取消下一次更新。进入应用或重启阶段后不再提供取消构建。
- “停止实例”停止所选实例；有共享构建时同时取消该构建，其他实例不因这次停止操作退出。
- “暂停日志显示”仅冻结日志面板，构建、任务反馈和实例仍继续。界面持续说明其作用，不再用含糊的“暂停展示”。
- 刷新页面 / 重新连接恢复后台任务；断线提示状态待确认。重复点击不会反复排队。保留的是当前执行器会话中的最近任务，退出执行器后不承诺恢复历史任务。

本版升级需要完整替换执行器与前端，不能只覆盖 `web`；保留 `web/` 与 `agent/`，升级前停止旧实例、退出旧执行器并备份配置。

**取消不回滚 Maven 已经写入磁盘的内容。** 原有兼容模式下，“未停止旧进程”不等于磁盘输出完全隔离。未签名开发预览，未直接验证用户 PMS、企业私服与长期负载。
