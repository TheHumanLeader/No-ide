# 运行台 · 第一版交互设计

日期：2026-09-20。状态：供用户操作评审，尚未确认最终界面。

## 设计重点

打开页面，先知道哪些服务在运行、发生了什么、下一步点哪里。文件树和编辑器不占据首页中心。

默认明亮粉色、中文操作；另提供明亮星空蓝，不自动切到暗色。轻量过渡，尊重系统减少动态效果偏好。

## 信息布局

左侧：工作区导航、固定工作区、执行器状态。中间：服务列表，独立运行 / 停止 / 重新运行。右侧：当前服务的运行信息、结果预览、运行配置。下方：运行日志、问题、变更记录。

顶部提供工作区、搜索服务和主题切换。运行台主操作为添加项目、运行全部、停止全部。

## 已实现的前端交互

- 六个示例服务覆盖 Java / Spring Boot、JavaScript / Vue / Quasar、Python、网关多服务、Android 和 Node.js。
- 更新流程：发现改动 → 构建 → 更新 → 就绪。展示模块热替换、应用重启、进程重启或重新部署。
- 模拟构建失败不改动当前版本和运行状态；错误面板提供复制给 AI、重试更新。
- 更新时再发生改动，会合并到下一次任务。停止会使未完成的回调失效。
- 全局和单服务自动更新开关。关闭后记录待处理改动，由用户手动应用。
- 添加项目、端口校验、重复名称校验、配置编辑；只修改当前预览会话。
- 日志搜索、服务范围、错误过滤、暂停展示、导出和清空。缓冲上限 500 条 / 96 KiB，渲染最近 120 条；不是完整历史虚拟滚动实现。
- Ctrl / Cmd + K 搜索服务；Esc 关闭弹窗，弹窗有焦点约束。
- 项目管理、运行记录、环境设备说明、主题切换和紧凑布局。
- 响应式布局：窄屏上下排列，手机侧栏改为抽屉。

## 诚实边界

持续显示交互预览和执行器未连接。示例接口不会发网络请求；Android 示例设备不代表真实连接。工具链页统一显示未检测，不显示虚构资源占用。

最终交付的单文件和源码均使用真实 Quasar。正式构建和交互检查记录见 `../verification.md`。
