## 用户操作

日常使用“运行”或“增量构建”，默认走指纹比较和按模块复用。“清理重建”独立显示，并要求再次确认，作为完整修复操作，不是日常验证入口。

首次使用需要建立可信构建基线，此后源码和构建环境不变，不再因为停止实例或退出 No-ide 就重新清理全部所需模块。构建指纹保存在 No-ide 本机配置数据目录的 build-state/，不进入项目源文件或 Git/SVN 分组。

升级前停止旧实例并退出旧执行器，建议备份原有 settings.json。完整解压新目录，保留 web/，双击 Start-No-ide.bat，确认本机控制台显示 v0.4.4；仅换 web 不能更新 Rust 构建策略。原有项目和环境配置继续沿用。

## 实际构建策略

- 使用 Maven 生效后的模块模型、依赖关系、源码与资源目录，而非只凭目录名称推测依赖。
- 源码/资源、编译输出与已安装同版本制品记录内容 SHA-256；不仅依赖文件修改时间或上次成功标记。
- 改入口模块：只选择入口模块重编，复用未变上游模块。
- 改公共模块：选择该模块及依赖它的下游模块。对公共常量、方法和类型修改采用保守的下游重编，不猜测 Java ABI。
- 删除类、内部类或资源：清理并重编受影响模块，避免旧字节码或资源残留，不清理未变上游模块。
- 已安装本地 JAR 被替换、target/classes 被删除，也会使相关模块失效。
- 先保存 dirty 状态，再运行编译；构建失败或取消不记录为最新。成功后再次核对构建输入及环境，防止构建期间变化被记成已完成。
- POM、JDK、Maven、settings、构建环境、文件激活的 Maven Profile 等变化会重新核对模型及基线。
- 未建模的自定义生命周期插件、扩展、未解析或不支持的路径等保守构建，并在日志明示原因，不把未知状态伪装为缓存命中。

每次实际构建选择通过 build-selection / build-plan 日志列出重编和复用模块及耗时。配置页的命令预览为完整基线命令，不能据此断定每次都在执行全部模块。

## 33 项新增真实增量验证

`tests/maven-incremental-044.py` 使用隔离的临时 Maven 仓库、真实 Maven、Java 8、Spring Boot 2.5.15 和合成模块 root/common/stable/app；另有一个故意编译错误的 unrelated 模块，确认不会被误选。没有运行、上传用户 PMS 代码或企业私服资料。

重点验收：

1. 第一次构建建立基线；停止再运行以及真正退出/重启执行器后，未变模块不重新构建。
2. 修改入口源码并恢复原文件时间戳，实际接口仍返回新内容；上游依赖 JAR 的字节摘要及修改时间保持不变。
3. 修改公共模块的编译期常量，下游重新编译，HTTP 与实际浏览器 WebSocket 均返回新常量。
4. 删除类、内部类和资源，通过实际运行时 Class.forName/资源查询确认不再被加载，稳定模块仍未重编。
5. 覆写已安装依赖 JAR、删除编译输出会触发针对性修复。
6. 构建失败不启动错误版本；修复源码后仍会编译，不会因为缓存存在就跳过。
7. 完整修复与普通增量按钮分离，拒绝确认不触发全量操作，API 同样要求确认。
8. POM 修改、文件激活 Profile 新增/删除引发模型更新，切换源码目录后验证实际接口内容，而非仅查看日志标签。
9. 无关损坏模块未构建，浏览器无未捕获错误。

## 边界与尚未解决项

这是模块级增量，不是 Java 单文件最小编译或 JVM 原地 HotSwap。Spring Boot 仍由 Maven spring-boot:run 启动，该目标本身可能进行入口生命周期检查；缓存命中表示跳过 No-ide 独立构建阶段，不表示完全不运行 Maven。

受影响模块仍会清理重编以可靠处理删除和公共接口影响；依赖很多模块的公共基础代码变化，影响范围也会较大。首次基线、构建结构变更以及未知插件仍可能完整构建所需依赖范围。启动参数和 Spring 初始化耗时单独存在，本轮没有通过绕过业务初始化或更改 Profile 来制造提速。

缓存比较局限于已选择本地工程和已解析依赖，未强制每次远端刷新 SNAPSHOT。复杂外部输入、生成器、构建扩展和企业私服配置需要真实工程验证；不能承诺任意 Maven 工程绝对安全命中。

产物仍来自原项目构建目录，尚未实现隔离构建/事务化发布；No-ide 不提前结束旧进程，不等于 DevTools 或延迟类加载观察不到磁盘变化。现有高级原始命令仍由用户控制，未自动改写。

Linux 新增增量专项通过，但已有日志自动滚动复选框回归仍失败，未生成可验收 Linux 包。Intel Mac 本次基础进程集成回归失败；不宣称整个工作流或全部平台通过。macOS 未运行本轮增量浏览器专项。本次交付明确为 Windows 已验证范围。

运行包未签名，属于开发预览。Windows Server 2022 CI 不等于用户 Windows 11 桌面、PMS 工程或长期负载验收。原有中文 Maven 安装路径下 Java 8 的独立限制仍未宣称解决。用户业务日志中的历史应用启动耗时不用于断言本版实际 PMS 耗时。
